02 / 下载

选择安装方式

当前版本 v0.1.2 · 开发者预览版

推荐

Chrome / Edge

适用于 Chromium 内核浏览器，也兼容 Brave、Arc、Vivaldi 等。

下载 ZIP ↓
  1. 解压 ZIP 文件
  2. 打开扩展管理页
  3. 开启开发者模式并加载文件夹

Firefox

独立清单与后台适配，适用于 Firefox 109 及以上版本。

下载 ZIP ↓
  1. 解压 ZIP 文件
  2. 打开 about:debugging
  3. 临时载入 manifest.json

油猴脚本

适用于已安装 Tampermonkey 的 Chrome、Edge、Firefox、Safari 等浏览器。

安装油猴脚本 ↗
  1. 先安装 Tampermonkey
  2. 点击上方安装按钮
  3. 在油猴页面确认安装
为什么不是商店一键安装？

Chrome 与 Firefox 目前提供开发者 ZIP 包；油猴版点击即可进入脚本安装页。首次使用前，请在雅译菜单中填写自己的翻译 API。
